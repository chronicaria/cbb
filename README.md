# College basketball power rankings

Men's college basketball power rankings and season forecast, served at https://chronicaria.github.io/cbb/.

Elo ratings in points against an average Division I team, with preseason priors blended from last season's rating
and KenPom / Bart Torvik preseason ratings, plus simulations of the rest of the season, every conference tournament
and the NCAA tournament. Every file here is generated by a nightly build; edit the source kit, not this repo.
